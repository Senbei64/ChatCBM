# ChatCBM on the Commodore 64

`src/c64/main.s` is the main program: input and output through the kernal, everything else in
the engine modules. The PRG loads at $0801; its first line is
`2026 SYS2083 REM CHATCBM: A TINY LLM`.

## Two memory modes

| mode | `$01` | interrupts | visible | used for |
|---|---|---|---|---|
| kernal | `$36` | on | RAM, I/O, KERNAL (BASIC banked out) | reading the question, printing a token |
| compute | `$34` | off | RAM only | tokenizer, model, sampler |

- **Zero page.** While computing, the program owns $02-$FF. The kernal also uses $90-$FF, so
  entering the kernal mode swaps that area with a saved copy (`kzsave`), and leaving it swaps
  it back.
- **NMI.** The RESTORE key is disabled at start: a CIA2 timer NMI is never acknowledged, so the
  edge-triggered NMI line stays low. With the ROMs banked out, no NMI can jump through the
  vectors at $FFFA, which are KV cache RAM.
- **Exit.** `/q` acknowledges that NMI and resets the machine.

## Memory map

| addresses | content |
|---|---|
| $02-$A8 | zero page of the program ($90-$FF swapped with the kernal) |
| $0801-$982F | PRG: BASIC line, code, tokenizer and sampler tables, model image (page aligned) |
| $9900-$9CFF | aligned tables: products, nibble decoding, attention products |
| $9D00-$A967 | activation buffers, tokenizer and sampler work areas |
| $A968-$BFFF | free (about 5.6 KB) |
| $C000-$FFFF | KV cache (16 KB, 4 layers): 4 KB of plain RAM and 12 KB under I/O and KERNAL |

## Screen

- **Text.** Lower-case character set, ASCII ↔ PETSCII conversion in both directions.
- **Wrapping.** Lines wrap between words. If the rest of a word split into several tokens does
  not fit the line, the word is deleted with DEL and printed again on the next line.
- **Sign of life.** While computing, the border changes color at every model step.
- **Fast mode (`/f`).** The screen is blanked (`$D011` bit 4) at the end of the first layer of
  every step and turned on again to print. The VIC-II then steals no badline cycles, about 5%
  of the time, and the program never waits.

## Speed

A PAL C64 runs at 0.985 MHz, a bit less with the screen on. That makes about 2.5 seconds per
answer token and 1.5 seconds per prompt token: the first word of the answer to *what color is
the frog?* arrives after about 12 seconds.
